# Job Application Tracker

This file preserves serious job-search activity across ChatGPT Project sessions and helps prevent duplicate applications.

## Status vocabulary

Use concise statuses where possible:

`discovered` · `shortlisted` · `preparing` · `applied` · `assessment` · `interview` · `follow-up` · `rejected` · `withdrawn` · `offer` · `closed`

## Active applications

No active applications have been migrated into this tracker yet.

## Application record format

Add one section per serious opportunity:

```markdown
### Company — Role
- Status:
- Location:
- Work mode:
- Source:
- Job URL:
- Date discovered:
- Date applied:
- Resume used:
- Fit / rationale:
- Compensation:
- Important screening answers:
- Recruiter/contact:
- Next action:
- Follow-up date:
- Notes:
```

Only record facts actually established from the job listing, application, connected tools, or Fares. Do not guess missing compensation, authorization, or application answers.

## Closed applications

Move or summarize completed/rejected/withdrawn opportunities here when the active section becomes difficult to scan. Preserve enough information to recognize duplicate future listings and understand prior outcomes.
